# SplitEvents

Telegram Mini App для организации совместных мероприятий.

## Структура проекта

```text

├── index.html

└── js/
    ├── telegram.js
    ├── nominations.js

        ├── event-card.js
        ├── events.js
        ├── page-shell.js
        └── servers.js
```

## Как устроен проект

- `index.html` — общий HTML-каркас приложения и подключение стилей и модулей.
- `app.js` — запуск приложения, маршрутизация и соединение модулей.
- `css/base.css` — общие дизайн-токены, типографика, цвета и светлая/тёмная тема.
- `css/components.css` — единая система кнопок.
- `css/layout.css` — шапка, основная область и безопасные отступы Telegram.
- `css/pages.css` — общие каркасы страниц и пустые состояния.
- `css/menu.css`, `css/profile.css`, `css/events.css` — стили соответствующих компонентов.
- `css/nominations.css` — оформление страницы номинаций и окон выбора с использованием общих токенов приложения.
- `js/telegram.js` — интеграция с Telegram Mini Apps API и синхронизация цветовой темы.
- `js/nominations.js` — логика выбора номинантов и формирования бюллетеня.
- `js/menu.js` — боковая навигация.
- `js/profile.js` — имя, аватарка и баннер профиля.
- `js/storage.js` — локальное сохранение профиля.
- `js/pages/page-shell.js` — общий каркас страниц.
- `js/pages/empty-state.js` — рендерер пустых страниц.
- `js/pages/event-card.js` — шаблон карточки события и обратный отсчёт.
- `js/pages/events.js`, `js/pages/servers.js` — содержимое разделов событий и серверов.
- `js/events/data.js` — каталог событий.
- `js/events/storage.js` — адаптер локального хранения списков ID.
- `js/events/active-state.js` — подсчёт активных и не скрытых событий.
- `js/events/hidden-state.js` — скрытие событий для пользователя на текущем устройстве.

## Единые правила интерфейса

Страницы разделов используют общие размеры заголовков, отступы и каркас. Кнопки используют класс `ui-button` и стандартные варианты оформления. Компоненты задают расположение и контекст, не дублируя базовую типографику, высоту и состояния.

Общие размеры, цвета, типографика, интервалы и скругления находятся в `css/base.css`. Цвета компонентов берутся из токенов Telegram; при открытии в обычном браузере используются системные светлая и тёмная темы.

## События

События описываются объектами в `js/events/data.js`. Каждое использует шаблон карточки из `js/pages/event-card.js`. Даты на карточках показываются в числовом формате `ДД.ММ.ГГГГ`.

Событие можно скрыть кнопкой с глазом. В режиме просмотра скрытых карточка получает кнопку с перечёркнутым глазом, возвращающую событие в список. Скрытые ID сохраняются в localStorage отдельно для Telegram-пользователя на текущем устройстве.

Счётчик рядом с пунктом «События» показывает количество активных и не скрытых событий. Срок активности определяется полем `endsAt`.

## Голосование

Кнопка «Принять участие» открывает внутренний маршрут `#/nominations?event=...` внутри Mini App. Страница использует общий заголовок приложения, шапку и навигацию; отдельная HTML-страница не создаётся.

В `js/nominations.js` настроены пять номинаций:
- PUMPKIN KING и PUMPKIN QUEEN — выбор участника из списка с возможностью добавить человека из общего пула;
- DUO ГОДА — выбор пары;
- DRIP ГОДА — выбор изображения или собственное предложение;
- NEXTGEN — выбор из фиксированного списка.

Для завершения бюллетеня необходимо заполнить все пять номинаций. Бюллетень формируется в браузере и доступен через `window.SPLITEVENTS_LAST_BALLOT` и событие `splitevents:nominations-submit`. Общая отправка и хранение результатов пока не подключены: для этого понадобится backend.

## Маршруты

- `#/` — главная.
- `#/profile` — профиль.
- `#/events` — текущие события.
- `#/servers` — сервера.
- `#/nominations?event=...` — голосование по событию.

Меню имеет фиксированный порядок: «Главная», «Профиль», «События», «Сервера», «Human Glaze». Human Glaze пока отключён и помечен как «скоро».

## Публикация и ограничения

Проект публикуется как статический сайт GitHub Pages из корня ветки `main`. Сборка и пакетный менеджер не требуются: браузер загружает ES-модули напрямую.

После изменения CSS или JavaScript обновляйте query-параметры версий в `index.html` и соответствующих импортах модулей, чтобы Telegram WebView не использовал старые ресурсы из кэша.

Приложение пока не имеет backend. Профильные изображения хранятся в IndexedDB, имя и состояние событий — в localStorage. Для синхронизации голосов между устройствами и приёма бюллетеней понадобится серверная часть.
