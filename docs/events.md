# Добавление событий

Список событий находится в `js/events/data.js`. Приложение поддерживает **несколько событий одновременно**: каждый объект массива `EVENT_RECORDS` превращается в отдельную карточку на странице «События».

## Как добавить событие

1. Откройте `js/events/data.js`.
2. После предыдущей записи поставьте запятую.
3. Добавьте новый объект с собственным уникальным `id`, названием, датой, временем окончания и описанием.
4. Сохраните файл. Отдельно создавать HTML-карточку или менять шаблон не нужно.

Пример второй записи:

```js
{
    id: "summer-meetup-2027",
    title: "SUMMER MEETUP",
    dateLabel: "15.06.2027",
    endsAt: "2027-06-15T23:59:59",
    description: "описание летней встречи",
    actionLabel: "Принять участие"
}
```

Правила:
- `id` — уникальный идентификатор на латинице, строчными буквами, с цифрами и дефисами. Не меняйте его после публикации: к нему привязаны имя папки с обложкой и состояние скрытия события.
- `title` — заголовок карточки.
- `dateLabel` — дата для отображения.
- `endsAt` — дата и локальное время окончания в формате ISO без часового пояса, например `2027-06-15T23:59:59`. От него зависит таймер и активный счётчик. Поле можно не указывать, если событие не ограничено временем.
- `description` — описание карточки.
- `actionLabel` — подпись на кнопке участия; необязательна.

Повторяющиеся или некорректные ID, пустые названия/даты и неверное время окончания останавливают загрузку каталога с понятной ошибкой в консоли. Это предотвращает незаметную путаницу между карточками.

## Обложка

Для события с ID `summer-meetup-2027` загрузите в ImageKit Media Library:

`/splitevents/events/summer-meetup-2027/cover.webp`

Изображение занимает левую половину карточки. Рекомендуемый размер — 970 × 500 px (соотношение сторон примерно 1.94:1), формат WebP. На телефоне изображение сохраняет пропорции и обрезается по центру через `object-fit: cover`; оно не растягивается. Важные детали композиции лучше держать ближе к центру. Сайт запрашивает обложку именно из ImageKit. Если файл отсутствует или не загрузился, карточка покажет штатную заглушку.

Каждая карточка получает собственный обратный отсчёт. Скрытие одного события не скрывает остальные, а счётчик в меню учитывает все активные и видимые события.

## Важное замечание об участии

Список карточек и обложек поддерживает любое количество записей. Сейчас кнопка «Принять участие» открывает общий экран голосования SQUASH 2026. Когда у другого события появится собственная программа, форма регистрации или отдельные номинации, его экран участия нужно будет подключить отдельно к ID события.
