# ImageKit: папки и изображения SplitEvents

URL endpoint проекта: `https://ik.imagekit.io/splitevents/`  
Корневая папка проекта в Media Library: `/splitevents/`.

Все изображения, которыми управляет сайт, находятся в Media Library под корневой папкой `/splitevents`. Сайт не использует внешние фотохостинги для этих файлов. Папка `/splitevents` — это корень библиотеки проекта внутри Media Library. URL endpoint уже содержит идентификатор `splitevents`, поэтому полный публичный URL имеет вид `https://ik.imagekit.io/splitevents/splitevents/<folder>/<file>`.

## Структура папок

```text

├── profile/                  # создаётся загрузкой из профиля приложения

    └── ...
```

## Серверы

Текущий сервер: TECHNOCRACY. В его папке должны лежать четыре файла.

| Файл | Назначение | Рекомендуемый размер |
|---|---|---:|
| `banner.webp` | Широкая обложка в обычной карточке сервера | 1940 × 500 px |
| `gallery-01.webp` | Первый слайд раскрытой галереи | 900 × 1200 px |
| `gallery-02.webp` | Второй слайд раскрытой галереи | 900 × 1200 px |
| `gallery-03.webp` | Третий слайд раскрытой галереи | 900 × 1200 px |

Папка: `/splitevents/servers/technocracy/`.

Формат всех файлов — WebP. Для баннера важные детали лучше располагать ближе к центру: в обычной карточке область изображения широкая и невысокая. Слайды галереи отображаются в высокой области раскрытой карточки на мобильном экране; предпочтительна вертикальная композиция 3:4. Изображения используют `object-fit: cover`, поэтому небольшая обрезка по краям ожидаема.

В карточке также отображается описание «сервер Minecraft». Оно является текстом и отдельный графический файл для него не нужен.

## Профили

Папка `/splitevents/profile/` уже используется Worker. Пользователь загружает аватар и баннер через страницу профиля. Имена файлов формируются автоматически с уникальным идентификатором, поэтому вручную добавлять или переименовывать профильные файлы не требуется.

Форматы загрузки: JPEG, PNG и WebP. Исходный файл должен быть не больше 20 МБ; перед отправкой приложение оптимизирует изображение, а Worker принимает итоговый файл размером до 5 МБ.

## События

Для каждого события создаётся отдельная папка по его ID. Для текущего события SQUASH! загрузите:

- Папка: `/splitevents/events/squash-award-2026/`
- Файл: `cover.webp`
- Рекомендуемый размер: 970 × 500 px.

Для будущего события с ID `summer-meetup-2027` путь будет `/splitevents/events/summer-meetup-2027/cover.webp`. ID события нельзя менять после публикации, поскольку он определяет путь обложки.

## Номинанты

## Проверка и резервные состояния

- Если изображение отсутствует или не загружается, интерфейс показывает штатную заглушку.
- Для событий и номинантов URL принимаются только из своей папки ImageKit endpoint проекта.
- Профильные изображения принимаются только из `/splitevents/profile/`.
- Не загружайте сюда логотипы интерфейса и SVG-иконки: они остаются частью кода сайта и спрайта Lucide.
