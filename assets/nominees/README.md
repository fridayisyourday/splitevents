# Изображения номинантов

Каждому номинанту соответствует файл WebP с квадратным изображением. Имя файла совпадает с его ID в базе номинантов.

Рекомендуемый размер — от 512 × 512 px. Если отдельного файла нет или он не загрузился, вместо него показываются инициалы.
