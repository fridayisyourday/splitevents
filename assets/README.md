# Статические изображения SplitEvents

Здесь хранятся изображения, которые приложение загружает напрямую из репозитория.

- Обложки событий: `assets/events/{event-id}/cover.webp`
- Аватары номинантов: `assets/nominees/{nominee-id}.webp`

Пути формируются централизованно в `js/media.js`. Если файл отсутствует или не загружается, интерфейс показывает предусмотренную заглушку.

Личные аватары и баннеры пользователей сюда не загружаются: они остаются в персональном хранилище профиля или берутся из Telegram.
