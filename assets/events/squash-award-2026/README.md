# SQUASH! 2026

Загрузить обложку события в эту папку под точным именем:

`cover.webp`

Путь: `assets/events/squash-award-2026/cover.webp`

Изображение занимает левую половину карточки. Для чёткого отображения на компьютере рекомендуем изображение 970 × 500 px (соотношение сторон примерно 1.94:1) в формате WebP. На телефоне изображение сохраняет пропорции и обрезается по центру через `object-fit: cover`, если узкая область просмотра не вмещает всю ширину. Важные детали композиции лучше располагать ближе к центру. Если файла пока нет, карточка события автоматически использует штатную заглушку.
